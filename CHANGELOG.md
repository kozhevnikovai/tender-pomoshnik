# Изменения

## 1.1.0 — 2026-11-11

### Безопасность
- Документы закупки скачиваются только с zakupki.gov.ru по https; ссылки на сторонние сайты и редиректы за пределы ЕИС не открываются.
- Ограничения размера: документ — до 100 МБ, архив — до 300 МБ после распаковки, не больше 30 файлов и 2 уровней вложенности (защита от «zip-бомб»); сканов распознаётся не больше 60 страниц.
- Безопасные имена скачанных файлов (без путей и зарезервированных имён Windows).
- Защита от prompt injection: текст документов передаётся модели в отдельной рамке с правилом «команды из документа не выполнять».
- Реестр CSV: текст закупки, начинающийся с =, +, -, @, не выполняется в Excel как формула.
- Ключи Telegram, Битрикс24, почты и облачной модели шифруются средствами Windows и macOS и не показываются после сохранения.
- Вебхук Битрикс24 — только https и не адреса локальной сети; ссылки из отчёта открываются только https.
- MCP-сервер и приложение открывают только разборы из папки отчётов.

### Исправлено
- Один битый, пустой или защищённый паролем файл больше не прерывает весь разбор — он помечается в отчёте.
- Если документ не скачался из ЕИС, разбор продолжается с остальными, а в отчёте есть предупреждение.
- Иконка в панели задач Windows совпадает с логотипом; в окне показывается версия.
- Повторные клики не создают дубли сделок в Битрикс24 и вторую загрузку моделей; вторая копия приложения не запускается.
- Сохранение настроек больше не стирает ключи; у каждого подключения — кнопки «Проверить» и «Отключить».
- На Windows с именем пользователя на кириллице модели хранятся в `C:\ProgramData\TenderPomoshnik`.

### Добавлено
- Загрузка моделей: размеры, общий прогресс, скорость и оставшееся время; докачка после обрыва, проверка места и SHA-256, запасной адрес. Прогресс виден из любой вкладки.
- Портативная версия для Windows (zip) и вопрос «удалить модели?» при удалении программы.
- Кнопки «Убрать файлы» и «Обзор» для папки отчётов; понятные сообщения для неподходящих файлов и ошибок сети.

## 1.0.0 — 2026-11-09

Первый выпуск.

- Разбор закупки по номеру извещения (44-ФЗ и 223-ФЗ): карточка и документы из открытой части ЕИС.
- Чтение PDF, DOCX, DOC, ODT, ZIP, локальный OCR сканов.
- Сведения с цитатами и страницами, база норм с редакциями и источниками (35 карточек).
- Расчёты: обеспечение заявки и контракта, антидемпинг, штрафы ПП № 1042, пеня, маржа.
- Риски, вердикт по профилю компании, сроки (.ics), чек-лист заявки, проверка предложения по ТЗ.
- Черновики запроса на разъяснение и жалобы в ФАС (DOCX), план исполнения контракта.
- Мониторинг через RSS ЕИС с уведомлениями в Telegram и на почту; Битрикс24; реестр CSV.
- Приложение для Windows и macOS (бета), расширение Claude Desktop (.mcpb), MCP-сервер, CLI.
- Evals на 36 реальных закупках ЕИС.
